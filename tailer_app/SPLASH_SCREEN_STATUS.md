## 🔧 Customization Options

### Change App Name
Edit: `lib/core/config/app_config.dart`
```dart
static const String appName = 'Your App Name';
```

### Change Splash Duration
Edit: `lib/core/config/app_config.dart`
```dart
static const int splashDurationDev = 3000;        // milliseconds
static const int splashDurationProduction = 2000;
```

### Change Tagline
Edit: `lib/features/splash/animated_splash_screen.dart` (line ~370)
```dart
'Your Custom Tagline Here',
```

### Change Native Splash Icon
1. Add image to `assets/images/your_icon.png`
2. Edit `flutter_native_splash.yaml`:
   ```yaml
   image: assets/images/your_icon.png
   ```
3. Regenerate:
   ```bash
   flutter pub run flutter_native_splash:create
   ```

### Change Animated Logo
Edit: `lib/features/splash/animated_splash_screen.dart` (line ~282)
```dart
Image.asset(
  'assets/images/your_logo.png',
  fit: BoxFit.cover,
),
```

## 🚀 Next Steps

### To Add Your Custom Icon:

1. **Prepare your icon:**
   - Size: 1024x1024 px
   - Format: PNG (transparent) or JPG
   - Professional, clean design

2. **Save it:**
   ```
   assets/images/splash_icon.png
   ```

3. **Update config** (if not using app_icon.png):
   ```yaml
   # In flutter_native_splash.yaml
   image: assets/images/splash_icon.png
   ```

4. **Generate:**
   ```bash
   flutter pub run flutter_native_splash:create
   ```

5. **Test:**
   ```bash
   flutter run
   ```
